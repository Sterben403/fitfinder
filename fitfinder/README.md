# FitFinder — ЖИ арқылы фото бойынша іздейтін киім дүкені

Пайдаланушы образды (аутфитті) суретке түсіреді немесе фотосын жүктейді, жасанды интеллект (ЖИ) суреттегі киімдерді танып, дүкен каталогынан ұқсас тауарларды табады.

«IT-жобаларды басқару» пәні бойынша өтпелі жоба, Л.Н. Гумилев атындағы ЕҰУ.

## Репозиторий құрылымы
- `docs/adr/` — жобалық шешімдер жазбалары (ADR)
- `docs/requirements/` — талаптар
- `docs/plan/` — жоспарлар, жеткізу модельдерін салыстыру, бэклог
- `src/` — бастапқы код
- `tests/` — тесттер
- `.github/ISSUE_TEMPLATE/` — тапсырма үлгілері (story, bug, tech, risk)
