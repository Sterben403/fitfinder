# KiimAI — жасанды интеллектісі бар киім дүкені

Пайдаланушы өз образының (аутфитінің) суретін түсіреді — жасанды интеллект (ЖИ) суреттегі киім заттарын танып, дүкен каталогынан ұқсас тауарларды табады.

## Негізгі мүмкіндіктер (жоспар)

- Суретті жүктеу немесе камерадан түсіру
- Суреттегі киім заттарын анықтау (жейде, шалбар, көйлек, аяқ киім, т.б.)
- Каталогтан көрінісі ұқсас тауарларды іздеу
- Нәтижелерді баға, өлшем, түс бойынша сүзу
- Тауар карточкасы, себет, тапсырыс

## Репозиторий құрылымы

```
docs/
  adr/            — архитектуралық шешімдер журналы (ADR)
  cases/          — ЛЖ-2: кейстерді салыстыру кестесі
  requirements/   — талаптар
  plan/           — жоспарлар
src/              — бастапқы код
tests/            — тесттер
.github/ISSUE_TEMPLATE/ — тапсырма үлгілері (story, bug, tech, risk)
```
