# KiimAI жобасының жарғысы

| | |
|---|---|
| **Жоба** | KiimAI — аутфит суреті бойынша ұқсас киімді іздейтін ЖИ |
| **Спонсор** | Оқытушы (шартты түрде — дүкен иесі) |
| **Жоба жетекшісі** | Мурзаканов Еснұр |
| **Күні / нұсқасы** | 23.09.2026 / 1.0 |
| **Негіздеме** | [Бизнес-кейс](business-case.md), [ADR-001](adr/0001-model-postavki.md), [қаржылық модель](finmodel.ods) |

## 1. Мақсаттар

1. Суретпен іздегендер арасындағы конверсияны **1,5%-дан 2,25%-ға** дейін **30.06.2027** жылға қарай арттыру.
2. Менеджерлердің қолмен іздеуге жұмсайтын уақытын **2,0-ден 0,6 сағ/күнге** дейін **30.06.2027** жылға қарай қысқарту.
3. **20.10.2026** жылға қарай іздеу сапасын **top-5 ≥ 60%** деңгейіне жеткізу (go/no-go нүктесі).

## 2. Жоба шекаралары

| Кіреді | **Кірмейді** |
|---|---|
| Суретті жүктеу немесе камерадан түсіру (веб) | Мобильді қосымша (iOS/Android) |
| Суреттегі киім заттарын анықтау | Виртуалды киіп көру (AR) |
| Каталогтан ұқсас 5 тауарды іздеу | Өлшемді ЖИ арқылы ұсыну |
| Баға, өлшем, түс бойынша сүзгілер | Онлайн-төлем және жеткізу логистикасы |
| Тауар карточкасы, себет, тапсырыс беру | Бірнеше дүкеннің ортақ маркетплейсі |
| Каталогты (5 000 SKU) көшіру | Каталогқа суретке түсіру (фотосессия) |
| Персоналды оқыту, ескі шешімді өшіру | Маркетинг пен жарнама науқаны |

## 3. Допущениелер

- Бастапқы бизнес-көрсеткіштер (80 000 кіру/ай, конверсия 1,5%, чек 25 000 ₸, маржа 40%) бағалау ретінде алынған. Нақты мәндер 1 апталық өлшеуден кейін нақтыланады.
- Ашық CLIP моделі 2-итерацияда top-5 ≥ 60% сапаға жетеді.
- Пайдаланушылардың кемінде 10%-ы суретпен іздеуді қолданады.
- Толық тізім бизнес-кейстің 9-бөлімінде берілген.

## 4. Шектеулер

- **Мерзім:** MVP 15.12.2026-ға дейін (семестр соңы).
- **Бюджет:** 1-жылы 9,07 млн ₸, 3 жылда 15,12 млн ₸ (TCO, C нұсқасы).
- **Команда:** 1 адам; ADR-001 бойынша Scrumban, 2 апталық итерациялар.
- **Заң:** пайдаланушы суреттері тек ҚР аумағында (PS Cloud) сақталады және өңделеді.
- **Технология:** тек ашық ПО (Python, CLIP, PostgreSQL/pgvector).

## 6. Табыс критерийлері

- 15.12.2026-ға дейін MVP іске қосылды: сурет → ұқсас 5 тауар, жауап уақыты ≤ 3 сек.
- Іздеу сапасы top-5 ≥ 60%.
- 1-жылғы TCO бюджеттен 10%-дан артық аспады.
- 30.06.2027-ге дейін 1-мақсат (конверсия 2,25%) және 2-мақсат (0,6 сағ/күн) орындалды.
- Жылдық әсер ≥ 6,05 млн ₸ (шығынсыздық нүктесі, бизнес-кейстің 7-бөлімі).

## 7. Жоба жетекшісінің өкілеттіктері

**Өзі шешеді:**
- итерация ішінде бэклогтағы басымдықтарды өзгерту;
- ашық стек ішінде технология таңдау;
- жылдық бюджеттің 5%-ына дейін инфрақұрылымға жұмсау.

**Спонсормен келіседі:**
- жоба шекарасын («кірмейді» бағаны) өзгерту;
- бюджетті 10%-дан артық өзгерту;
- вехаларды жылжыту;
- жеткізу моделін ауыстыру (ADR-001-дің қайта қарау критерийлері бойынша).

## 9. Эскалация шегі

Келесі жағдайлардың кез келгенінде жетекші спонсорға **2 жұмыс күні ішінде** хабарлайды:

- бюджеттен ауытқу **> 10%**;
- кез келген веха **1 итерациядан (2 апта)** артық кешіксе. Кешігу құны — айына **673 938 ₸**;
- 20.10.2026-да top-5 < 60% болса — жобаны тоқтату немесе бағытты өзгерту (pivot) шешімін қабылдау керек;
- жоғары тәуекел (R-01, R-02) іске асса.
