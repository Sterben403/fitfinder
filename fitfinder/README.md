# FitFinder — магазин одежды с ИИ-поиском по фото

Пользователь фотографирует аутфит (или загружает фото), ИИ распознаёт вещи на фото и находит похожие товары в каталоге магазина.

Сквозной проект по дисциплине «Управление ИТ-проектами», ЕНУ им. Л.Н. Гумилёва.

## Структура репозитория
- `docs/adr/` — архитектурные и управленческие решения (ADR)
- `docs/requirements/` — требования
- `docs/plan/` — планы, сравнение моделей поставки, бэклог
- `src/` — исходный код
- `tests/` — тесты
- `.github/ISSUE_TEMPLATE/` — шаблоны задач (story, bug, tech, risk)

## Модель поставки
Scrumban с недельными итерациями — см. [ADR-001](docs/adr/0001-model-postavki.md).
